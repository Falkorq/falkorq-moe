# Разработка falkorq.moe

## Запуск

Из корня репозитория запусти `python -m http.server 8765` и открой http://localhost:8765/. Используй HTTP вместо открытия HTML как файла: это позволяет корректно проверять загрузку ресурсов и Clipboard API на localhost.

## Стили и ресурсы

`index.html` подключает стили в порядке `fonts.css`, `style.css`, `personal.css`. Персональные стили дополняют основной дизайн и переопределяют его палитру и типографику.

Шрифты Days One, IBM Plex Sans и JetBrains Mono находятся в `assets/fonts/`. Рядом сохранены их лицензии. Иллюстрации находятся в `assets/`; пути к ним указаны в HTML и CSS.

Сохраняй идентификаторы секций, атрибуты `data-scroll`, доступные названия кнопок и поддержку `prefers-reduced-motion`: они используются навигацией и взаимодействиями.

## Музыкальный виджет

Настройки находятся в `SITE_CONFIG.statsFm` в начале `script.js`. Виджет запрашивает последний трек через публичный API stats.fm и сохраняет его в `localStorage`. При недоступном API он использует кэш или запасное состояние. Секретный API-ключ для этого запроса не предусмотрен.

## Проверка изменений

Автоматическая команда тестов в репозитории не настроена. Проверь страницу в браузере на широком и узком экране:

- Первый экран открывается и прелоадер исчезает.
- Навигация ведёт к нужным секциям.
- Иллюстрации и локальные шрифты загружаются.
- Музыкальный виджет корректно показывает трек или запасное состояние.
- Копирование в разделе поддержки работает.
- При уменьшенном движении анимации не мешают чтению.
- В консоли нет новых ошибок.

## Публикация

Сайт можно публиковать с любого статического хостинга. Каталог публикации — корень репозитория; сборка не требуется. `package.json` и каталог `dist/` не нужны.

Домен сайта — https://falkorq.moe/. Подключение домена выполняется в настройках выбранного хостинга. Метаданные Open Graph и Twitter находятся в `<head>` файла `index.html`.

URL ресурсов используют параметры версий `?v=...`. При замене CSS, JavaScript или изображений обновляй соответствующие версии в HTML, чтобы браузеры загружали свежие файлы.
